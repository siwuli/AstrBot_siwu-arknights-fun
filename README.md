# 兔兔 - 明日方舟娱乐整合（arknights_fun）

AstrBot 插件：**签到 + 模拟抽卡 + 猜干员** 三合一，统一「寻访凭证 / 合成玉」经济闭环，
玩法对齐 Amiya-Bot 生态（amiyabot-user 签到、arknights-gacha 抽卡、game-guess 猜干员），
但收敛进**同一个插件**，数据自包含、零跨插件耦合、开箱即用。

> 插件 id：`arknights_fun`　当前版本：`1.3.11`　适用 AstrBot `>=4.0.0`

## 经济闭环

| 途径 | 获得 | 说明 |
| --- | --- | --- |
| `签到` | 寻访凭证（默认每天 50 张） | 也可配置额外合成玉 |
| `猜干员` | 合成玉 | 答对 +300×难度倍率×连击（可配置）；每局前三名再奖 3000/2000/1000×倍率 |
| `抽卡` | 消耗 | 优先扣寻访凭证；凭证不足按 600 合成玉/抽抵扣（均可配置） |

合成玉持有上限默认 30000（`jade_max`），阿米娅同款规则。

## 功能与指令

| 指令（需 @ 或唤醒词） | 效果 |
| --- | --- |
| `签到` | 每日领取寻访凭证；回复附带**浏览器渲染的用户信息卡片图**（使用 Amiya 原版 HTML/Vue/ECharts/JsBarcode 模板 + Playwright 截图，与原版完全一致），信赖 +50、心情回满 |
| `单抽` / `十连` | 单抽 / 十连（十连保底 5★） |
| `一百连` `三百抽` `30次寻访` `抽卡 100` 等 | 1~300 次任意连抽，**数字/中文数字均可** |
| `保底` | 查询水位、下次六星概率、余额 |
| `卡池` / `卡池切换 N`（或池名） | 查看/切换真实卡池（含 UP）；数据源为**阿米娅官方 gacha 接口**（与原版 amiyabot-arknights-gacha 完全相同，常驻/中坚/往期限定 101 池），启动时自动同步并按间隔自动更新，excel/内置兜底 |
| `box` / `我的干员` | 干员箱（文本 + 拼图） |
| `寻访凭证` / `我的资源` / `还有多少凭证` | 凭证、合成玉、抽卡统计 |
| `我的信息` / `个人信息` | 用户信息卡片图（同签到附图） |
| `猜干员` | 玩法说明；`猜干员 初级/中级/高级/资深` 开局（全员参与） |
| `猜干员排行` | 赛季积分榜 |
| `猜干员数据` / `数据状态` | 数据就绪/更新状态 |

猜干员进行中（与阿米娅一致）：**作答无需 @ 或唤醒词**，直接发送干员名即可；`提示` 要线索；`跳过` 公布答案；`结束竞猜` 终止；**游戏期间本群其他功能（抽卡/签到/查询等）与 LLM 回复全部暂停**，游戏结束自动恢复。
难度：初级（基础线索）/ 中级（技能名）/ 高级（语音台词）/ 资深（档案片段），
高级/资深数据不足时自动回退中级。

## 抽卡规则

- 概率：3★40% / 4★50% / 5★8% / 6★2%；连续 50 抽未出 6★ 后每抽 +2%，99 抽必出；干员池为**过滤后的真实可抽干员**（当前全量 419 名：6★145 / 5★195 / 4★62 / 3★17）；
- 十连保底 5★（可配置）；UP 干员按 50% 权重（可配置覆盖名单）；
- 抽卡/干员箱图片**完全复刻 Amiya-Bot 原版**：抽卡拼图使用官方素材组图（背景 bg.png + 稀有度边框 + 立绘中央裁剪 + 职业图标，整体 0.8 倍缩放）；
  `box` 输出按稀有度分组的头像+数量角标图；头像缺失自动从 GitHub 按需下载缓存；素材缺失时自动回退纯文本。
- 文字输出同步 Amiya 原样格式：≤10 抽为简历列表、>10 抽为高星统计文本，尾部为「当前已经抽取了 X 次而未获得六星干员…」保底信息；
  十连默认只发图+保底信息（与 Amiya `display_operator_name=false` 一致），可在配置 `gacha_show_pull_names` 开启显示干员名。

## 数据方案（可移植、零耦合、不重复下载）

- 数据下载到 **AstrBot 公共数据目录** `{data}/resource/gamedata`
  （与 arknights-query 等方舟插件约定一致，谁先下载谁用，只读不依赖）；
- 本插件自带独立下载器（标准库 urllib）：启动即查、后台全量/增量下载 excel JSON，
  默认每 24 小时与远端比对文件大小，只拉有变化的表（新干员/新卡池自动同步）；
  卡池另从阿米娅官方 gacha API（cdn.amiyabot.com/api/v1/gacha）自动同步真实池名/UP/池子图（与原版一致）；
- 跨插件目录锁（原子 mkdir 互斥），与其他插件并发更新互不踩踏；
- 下载前/失败时使用内置资产兜底（`assets/operators.json` + `assets/pools.json`），
  任何环境开箱即用。

## 管理后台（AstrBot 内置 WebUI）

安装后，在 **AstrBot 管理面板 → 插件页面** 中打开 `arknights_fun` 的管理后台（`dashboard`），可：

- 📊 概览：用户数、累计抽数、发放凭证/合成玉、数据状态（excel 文件数、上次更新、干员/卡池/语音规模）；
- 👥 用户管理：按累计抽数排序的用户列表，支持调整凭证/合成玉、重置保底水位、删除用户（用于补发签到奖励、修正数据等）；
- 🗄️ 数据维护：一键触发 gamedata 增量更新（与定时更新共用互斥锁）；
- 🔮 卡池管理：查看每个卡池按星级分组的**完整可抽干员名单**、当前 UP；可直接编辑 UP（按池覆盖，优先于全局配置 `gacha_pickup_6/5`，存 `pool_overrides.json`）。

> 干员池口径：从 gamedata 加载时**排除召唤物（token/trap、TOKEN 职业）与预备干员**，只保留可寻访的真实干员（`char_` 开头），如「此面向敌」「预备干员-近战」等不会出现在任何卡池。

页面前后端均随插件打包分发，无需额外安装依赖。

## 配置项（管理面板或 AstrBot 配置界面）

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `fun_user_title` | 博士 | 对用户的称呼 |
| `sign_enabled` / `sign_coupon` / `sign_jade` | 开 / 50 / 0 | 签到开关与每日发放 |
| `sign_feeling` / `sign_card_enabled` | 50 / 开 | 每次签到信赖值；签到/我的信息是否发送卡片图 |
| `jade_max` | 30000 | 合成玉上限 |
| `gacha_enabled` / `gacha_free` | 开 / 关 | 抽卡开关 / 免费模式 |
| `gacha_coupon_init` / `gacha_jade_init` | 10 / 0 | 新用户初始资源 |
| `jade_per_pull` | 600 | 凭证不足时的玉消耗/抽 |
| `gacha_guarantee5` | 开 | 十连保底 |
| `gacha_pickup_6` / `gacha_pickup_5` | 空 | UP 覆盖名单（阿米娅官方卡池接口无 UP 时才用它） |
| `gacha_render_image` / `gacha_fetch_avatar` | 开 / 开 | 出图与头像自动下载 |
| `gacha_show_pull_names` | 关 | 十连消息里同时显示干员名称（对应阿米娅 display_operator_name） |
| `gacha_image_font` | 空 | 自定义字体路径（留空自动检测） |
| `gacha_auto_update` / `gacha_update_interval_hours` | 开 / 24 | 抽卡数据自动更新 |
| `guess_enabled` / `guess_questions` / `guess_timeout_sec` | 开 / 5 / 60 | 猜干员开关、题数、每题超时 |
| `guess_points_bingo` | 100 | 猜对基础得分 |
| `guess_jade_bingo` | 300 | 猜对基础合成玉 |
| `guess_jade_rank1/2/3` | 3000/2000/1000 | 每局前三名合成玉 |
| `guess_auto_update` / `guess_update_interval_hours` | 开 / 24 | 猜干员数据自动更新（与抽卡共用任务） |

## 安装

1. 打包：`python plugins/astrbot/siwu-arknights-fun-1_0/build.py`
2. 产物：`plugins/astrbot/dist/siwu-arknights-fun-1.3.1.zip`
3. 管理面板上传安装，或解压到 `data/plugins/arknights_fun/` 后重启 AstrBot。

> 升级提示：若之前单独装过 `arknights_gacha` / `guess_operator` 旧插件，
> 请先停用/删除旧插件再启用本插件（指令覆盖会重复）；旧用户数据会在首次启动时自动迁移。

## 验证

1. `签到` → 领取 50 张寻访凭证；
2. `十连` → 返回 10 位干员文本 + 拼图，凭证扣除；
3. `一百连` / `三百抽` → 中文数字识别，1~300 次连抽；
4. `猜干员 初级` → 群内开局，答对得合成玉；`我的资源` 查看经济变化；
5. `数据状态` → 查看数据就绪与上次更新时间。
